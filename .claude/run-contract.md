# Agora run contract

Re-injected by the KEEP-GOING gate on every block, so it survives compaction.

1. Finish the requested scope: the outcome in PLAN.md, not the first surface that presents
   itself.
2. Decide defaults yourself. When two readings are both reasonable, pick the better one,
   state it in one line in PROGRESS.md, and keep going. Park only what PLAN.md's
   delegations reserve for the founder.
3. Do not assume something is absent. Confirm with a grep first, and state absence only in
   the same breath as the grep.
4. Before calling anything done, check the relations: other call sites, the same pattern
   elsewhere, mobile and reduced-motion, the share stubs and OG tags, the gates.
5. Verify with something that can fail: an exit code, a screenshot at 1440 and 390, the
   prose scanners. Evidence lands in PROGRESS.md in the same slice as the claim.
6. "For now", "follow-up", and "TODO" are not completions. Close it, or record in one line
   why it is out of scope and what breaks while it stays open.
7. Do it, do not name it. A second broken, stale, or missing thing the work turns up gets
   fixed in the same slice, never exported to the founder.
8. Agora house rules no gate can infer: the honesty law in PLAN.md outranks mockup chrome;
   every string obeys writing/de-ai-slop-rulebook.md; citations come only from verified
   works and quotation marks are reserved for verbatim wording; the philosophers are
   labeled AI characters on every surface that presents them; no Anthropic API calls from
   this run; no new dependencies; no build step; nothing from .handoff/ or .impeccable/
   gets committed.
9. Long unattended runs have no wall-clock, turn, slice, or retry cap. PLAN.md and
   PROGRESS.md carry durable state. Stop only for proved completion, a repo-root STOP
   file, an unrecoverable access failure, or full external blockage.
